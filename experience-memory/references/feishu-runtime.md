# 飞书运行与配置

飞书工作伙伴先按 [固定库调用规则](feishu-host-library.md) 读取 ../config/feishu-library.json；当前优先在项目或参考记录附件中保存原件，用多维表格保存结构化价格及经验。storage.example.json 仅为旧本地工具示例，不是宿主连接配置。只有已提供真实目标和授权能力时才操作，不能猜 token 或全盘搜资料。

首次配置：确认云盘 folder_token、多维表格 base_token、项目表/价格版本表/经验参考表的 table_id 与实际字段映射、当前 user/bot 身份。缺目标时询问一次，继续本地准备；不默认创建新应用或擅自扩权限。

原件上传/文件导入使用宿主飞书云盘工具；在已存在 Base 内写记录使用其记录读写工具。执行前查看当下工具 schema/help 和字段类型，不假定旧 CLI 参数永远可用。没有 CLI 时可用等价已授权连接器。技能包不内置密钥或独立服务。

## 保存顺序与回执

1. 登记项目及报价阶段，读取当前版本，准备待写记录。
2. 将原件和成果上传到配置目录，取得 file_token/链接；已上传相同哈希则复用现有来源。
3. 在价格版本表追加 record_id+revision_id 对应记录，payload_json 与常用查询列一致。用 expected_revision 与当前版本比较；单写入者防止并发覆盖。缺失历史前驱时先恢复前驱，不跳过版本链。
4. 回读关键字段及版本，确认写入一致后更新当前版本指针/登记。重复执行查询同键后复用，不重复插入。
5. 保存本次回执：项目、文件 token、Base/table/record_id、版本、核验时间、成功/失败条目。部分成功保留待重试，不声称全部入库。

只有最终结果明确时才将 price_type 写成 final_negotiated 等。报告完成本身不是谈判完成证据。平台授权后，可在当前询价任务结束时按本流程连续保存，无需每条弹窗；这不等于安装 Skill 就具备后台事件监听或定时运行。

暂时失败有限重试一次，权限/目标错误停止；不换身份绕过授权。未上云的本地记录显示 pending_sync，不保证无持久卷下跨会话可用。

## 查询

回标 Skill 使用同一配置的只读权限；按项目关键字、单位等召回，翻页后由 AI 核对范围、日期、税运和价格阶段。接入未知宿主前必须用一个脱敏项目测试：上传→写记录→回读→新任务查询→修订→旧版本仍可追溯。

## 旧库迁移

v1 原始目录只读备份，不覆盖。旧 case.json 转换时保持 project_id、投标人、轮次和原始来源；缺字段为 pending。memory.json 保留状态，旧 active 也需核对适用条件；不把休眠/待复核强制变为 active。迁移完成前维持旧库可恢复。本版不自动批量迁移未知位置的真实库。
