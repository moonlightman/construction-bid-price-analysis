# 可选补充分析

AI 根据工程特点选择，不以完成所有方法为目标。每项新增分析保存“采用原因、输入与来源、方法或公式、结果、限制”，可增加 Excel 标签页，重要发现回填基础结论与澄清表。

## 常见选择

| 报价特点 | 可采用的方法 |
|---|---|
| 少量设备/材料占比较高 | 主要费用排序、累计占比和总价敏感性 |
| 材料与施工分列 | 两部分差额贡献、范围与重复计取核查 |
| 同类项目存在多个规格 | 同规格一致性、规格差异解释；不强定线性价格规律 |
| 工程量暂估或变更敏感 | 有依据的工程量情景分析 |
| 多轮报价 | 同范围降价贡献，区分价格变化与范围变化 |
| 人材机组成充分 | 组成与取费口径分析 |
| 综合价缺少组成 | 同行、历史、市场、独立估值中的可得证据 |

## 费用组成

识别人工、材料、机械、管理、利润、风险、规费和税金；每列保留原表头、单价/合价/费率/汇总金额口径、计取基数及来源。无法确认口径的字段不参加横向统计。

只有源表定义为可加且组成完整时才核验组成合计等于综合价。部分列可见时仅展示已披露金额与未覆盖范围，不能将未覆盖部分直接认定为漏项。管理利润合并列不能与分列重复相加，分部分项与汇总表也不能重复计入。

## 公开市场证据

在用户要求，或高影响问题需要外部参照且环境有获批检索能力时开展。只发送通用名称、规格、地区和日期，不发送原件、供应商、内部报价或控制价。

优先官方造价信息、可核验成交记录、制造商及授权渠道；零售价格是辅助线索。高影响结论尽可能采用两个独立来源，不能把转载当独立证据。

保存发布者、标题、链接、发布日期/有效期、访问日、规格、单位、原价、税运安装范围、换算及调整后价格。按本次计价时点判断可用性；晚于计价日的公开价格不能伪装成当时价格。外部能力不可用时说明限制，继续现有证据分析。

必须将实际核验的网页链接写入 Word 联网比价表和 Excel 对应价格记录旁，按 [来源链接规范](source-links.md) 执行。只在底稿保存 URL、只在聊天回复贴链接，或在文末集中放无法对应报价的链接，均不算完成。

## 独立参考估值

仅在有可靠消耗量、资源价和适用取费依据时计算：材料消耗×材料价＋人工消耗×人工价＋机械消耗×机械价＋有依据的其他费用。取费基数、利润、风险和税费分别说明；可有低/基准/高三档，但不能为了凑价反推消耗量。

该估值不是投标人的真实成本。没有可靠输入时不强制建立成本表，也不强制输出方向性结论。依据可得同行、历史等证据给出适当意见，或明确证据不足。
