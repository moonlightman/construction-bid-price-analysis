# 算法选择、诊断与验证

## 先定义对象和问题

四维结构分析是主流程，算法用于发现基础比价遗漏的组合差异。`bidder_project` 是一个投标人在一个项目/轮次的报价结构；5000条清单、10家投标人不等于50000个独立整份报价样本。`comparable_item` 是经复核的同规格/同范围记录；不同单位项目不得混作价格样本。历史不同阶段、不同版本不能冒充独立样本。

AI在任务内形成方法计划：样本单位、比较群、特征/单位、变换理由、样本与独立项目数、覆盖率、缺失规则、预期能新增发现的问题、拟执行/暂不执行理由。不逐方法要求用户确认。

## 特征与预处理

- 优先有工程含义的特征：可比单价指数、统一量价差占比、类别正负价差、费用占比、已确认关联指标；当前同行参照与历史参照分开。
- 全清单高维先按业务聚合，不用PCA掩盖独立对象太少。未确认映射、缺失、算术异常、库状态冲突不进入基准或拟合。候选记录仍可展示。
- 保留原值及来源、标准化和时间/地区调整依据。比例的分母为零/近零、负值及残值净价单独分析；不自动补零、对数化或缩尾。正值对数变换须在特征定义中记录。
- 批内探索可对本批缩放；跨项目验证必须在训练折拟合基准、缩放、PCA及阈值，再应用验证/测试数据。不能全量预处理后再拆分。
- 不把原报价、归一化报价和其合价全部当作相互独立特征重复加权。金额影响另行呈现，不让昂贵项目或冗余列无意主导距离。

## 算法作用与证据要求

| 方法 | 问题与输出 | 关键设置/验证 |
|---|---|---|
| PCA | 提取主要差异方向；输出载荷、解释方差、重构残差 | 缩放后拟合；保留原特征异常检查，低方差不代表低业务风险；不把载荷说成因果 |
| K-means | 识别结构相近的组；输出分组、中心距离、簇规模 | 比较多个k、初始化种子与轮廓系数；稳定分组也不代表有效风险分类，小簇不自动异常 |
| LOF | 相邻同类对象中的局部离群；输出分数及邻居数敏感性 | 批内用novelty=False及negative_outlier_factor_；预测新样本需另训novelty=True，不对训练样本调用新颖性评分；不强制异常比例 |
| KDE | 连续特征的稀疏区间；输出对数密度及带宽敏感性 | 本工具逐特征留一核密度，低密度不是高风险概率；不同量纲/维度的密度不能直接比较或相加 |
| 贝叶斯优化 | 按验证目标选择参数；本工具只优化冻结分数阈值 | 先定漏报/误报/复核成本目标，按项目隔离；最终留出集不参与参数搜索，不自动部署候选阈值 |

## 两类运行必须分开

### 当前批次探索

`python scripts/structure_algorithms.py features.json --output diagnostics.json`

需 numpy 与 scikit-learn；缺依赖返回 dependency_unavailable，不自动联网安装。返回源索引、特征定义、输入哈希、运行库版本与参数，适用状态包括 exploratory/not_evaluable。六个有效对象、维数不高于对象数三分之一仅是此脚本的保守运行起点，不是通用有效性证明。恒定列删去并记录；缺失行列明排除；不同取值不足时不勉强聚类或KDE。

脚本实际执行：RobustScaler；PCA保留90%方差并输出残差；在原缩放特征比较k=2至min(5,n/3,不同对象数-1)，种子42/7/19；LOF比较约n/4和n/2邻居；KDE逐特征带宽0.5/1/2倍敏感性。原特征偏离用于解释，PCA不默认替代原特征。内部指标和敏感性不是准确率，不输出统一风险概率。

### 独立项目效果验证及参数校准

先由AI/业务复核形成有来源的正常与异常标签；无投诉/无争议不等于已确认正常。明确标签针对何种可核查问题，不把价格模式标为违法行为。按项目整体分组，多个投标人、轮次和清单不能穿越训练与测试；按时间防未来信息泄漏，供应商重复相关性也应检查。

对比基础偏离/金额方法与算法新增发现：按项目报告漏报、误报、召回率、精确率、人工复核量、重大问题和金额、样本规模与置信限制。没有标签只报告探索性差异，不能声称准确率。业务价值要回到额外发现的真实问题。

`python scripts/calibrate_threshold.py calibration.json --output calibration-result.json`

需 scikit-optimize。只接收已冻结、分数越大越异常的项目外评分及真实复核标签；不是重新训练模型的万能接口。至少4个校准项目、2个留出项目（两侧均有正反例）为本工具运行起点，不保证推广能力。24次GP搜索，种子42，按项目等权计算漏报/误报/复核量损失。与预先登记阈值在最终留出集上比较，保存试验轨迹及逐项目结果；候选即使优于基线也需业务审核，不能自动改正式规则或写经验库。

## 重现、说明与保存

保存特征数据哈希、采样时间、样本/项目数、训练与验证项目清单、参数、随机种子、软件版本、基准与候选结果。没有宿主计算能力时保留分析计划和待计算底稿，不编造分数。给出输出源表跳转和方法状态；多个方法命中同一清单合并 finding_id，不重复金额。授权保存后按 experience-memory 的算法反馈规范存入经验与参考；不得将模型分数写为历史单价。
