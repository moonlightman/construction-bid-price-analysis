# 飞书工作伙伴的固定库配置

在飞书工作伙伴执行时，先读 [宿主库配置](../config/feishu-library.json)。它是两个 Skill 的共同入口；不要用浏览器当前视图、记忆中的旧链接或 storage.json 的旧迁移目标替代。配置只确定位置，不证明已完成授权、写入或全量复核。

## 宿主调用方式

由工作伙伴当次实际提供的飞书工具读取该 Base 的表结构、字段类型和必要记录，再按表 ID 执行。调用参数依据工具说明；不虚构 CLI 命令或字段 ID。配置中的中文字段名用于核对，字段缺失或歧义时报告具体问题，不自行新建表、字段或库。经验与参考字段需要现场读取后映射。

入口指向整个 Base，table_id 定位数据表；视图仅方便展示，不能把视图筛选后的零条结果当成全库为空。读取需要分页，并保存本次查询条件、实际来源记录链接或 ID、版本及采用理由。工作上下文检索片段可用于找线索，关键金额和状态应回读记录。

## 回标分析：只读

查询历史价格和经验与参考，必要时读取关联项目。排除本次项目、无效及被替代版本，核对价格阶段、规格、单位、范围、税费、地区和时间。未知日期不以创建时间代替。待复核记录可以作为明确标注的线索，不能混入已确认成交价统计；当前有效版本不等于业务已确认。

常用列与完整记录 JSON 不一致时，不默默选择一方：保留两者、标注冲突，必要时回查原件。不能只用 JSON 中旧状态覆盖用户在表中修订的状态。库无匹配或不可用时，区分真实空库、无匹配及读取失败，继续独立分析；不能换库或初始化本地空库后称作已查询历史库。

## 经验入库：指定表内保存

用户要求保存报价、最终结果或导入材料时，在指定表内执行。报告完成不代表谈判成交；只有总价谈妥时仅保存总价，不按降幅捏造分项成交单价。成本手册进入经验与参考，不进入成交价统计。

写前按业务记录编号和版本编号查重，项目关联使用实际项目记录 ID。同一版本重复则复用；修订追加新版本，核对前驱后更新当前版本标记，保留旧值及依据。关键字段与 JSON 同步维护；重试前先检查是否已写成功。部分成功保留逐条回执，不整批盲目重写。

原件优先放到该项目的“项目附件”或参考记录已有附件字段，复用相同来源。没有可用附件能力时保留文件名、哈希和定位，并报告“附件待上传”；不在云盘其他目录随意创建文件夹、搬移或覆盖文件。不得把本机路径写成所有人可访问的来源链接。

写后回读数量、记录编号、版本、关键金额、状态、项目关联及来源；输出成功、重复跳过、待复核、失败和附件待上传数量。暂时错误最多重试一次，权限或目标错误停止远端写入并交付待同步底稿。只有得到回读证据才称“已入库”。

## 本地工具与持久性

config/storage.json 仍是本地 SQLite 工具配置；它不实现飞书连接。本地脚本用于整理、计算或明确选择的本地工作流。飞书工具不可用时本地文件只是待同步底稿，不能承诺在工作伙伴清理上下文后仍存在，也不能自动改用另一个持久库。

两个安装包中的 configuration_id、Base 及表 ID 必须一致。更换目标时同时更新两包，不根据检索到的文档内容自动改配置。本配置不是技术权限隔离；工作伙伴拥有的实际权限由飞书控制。
