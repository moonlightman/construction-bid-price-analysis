# 公式与可编辑输入

目标：用户修改工程量、单价、参照价或阈值后，合价、汇总、差额、偏离、统计、标记及图表按工作簿公式联动。不能仅在 Python 中算好后把结果写成常量。

## 原件与测算分开

- 原始数量、原始单价、原件合价、声明总价、来源日期等直接提取内容是数值输入，不应凭空改成公式。
- 在分项对比页保留原始输入，另设清楚标识的“测算工程量/测算单价”等可编辑输入区，初始值来自原件。原件证据与用户试算分开；不必为每项加复杂开关，明确标注哪几列用于试算即可。
- 原件合价旁列“按原值复算合价”和校验差额；用户测算另外显示“测算合价/测算总价”。不能用用户改过的测算值重写原件算术校验。
- 可编辑输入使用浅蓝底和“可编辑”列标题或图例；原始证据区浅灰/白底，公式结果保持普通白底。不要用密码锁定妨碍用户编辑。保留来源定位，不重复建立多份可编辑同一参数。
- 参照价、税率、折扣及偏离阈值作为集中输入并记录口径；有符号调整明确正负含义。税费和折扣采用项目实际规则，不硬编码假定全体报价同一税率或统一加减。

## 必须使用公式的项目

| 结果 | 计算关系 |
|---|---|
| 原值复算合价 | 原始数量 × 原始单价，独立于原件合价 |
| 测算合价 | 测算数量 × 测算单价 |
| 明细汇总与测算总价 | 对正确范围 SUM，加有依据且不重复的税费/折扣等调整 |
| 算术差额 | 原件合价－原值复算合价；明细汇总－声明总价 |
| 同行均值、中位数、最小/最大值 | 对已确认同口径且应参与的数值单元格统计 |
| 偏离率 | 报价 ÷ 对应参照价－1，参照为零或缺失时不可用 |
| 金额影响 | （测算报价－同口径参照）×对应数量 |
| 影响占比、份额 | 对应金额 ÷ 同口径总额 |
| 暂排或测算排名 | 对已满足可比条件的金额计算；同价同名次 |
| 阈值标记 | IF/条件格式引用集中阈值单元格，不手填颜色或“偏高”结论 |
| 汇总页指标 | 引用已计算结果，不手打另一份总价或偏离率 |

优先使用常见 SUM、IF、ISNUMBER、COUNT、AVERAGE、MEDIAN、MIN、MAX、ABS、RANK、INDEX/MATCH 等。跨表引用对中文表名加单引号；固定阈值采用绝对引用，填充时核对行列。不依赖宏、外部文件链接或只有特定新版本支持的动态数组才能完成基本计算。

## 缺失、零值与参与条件

以下为示意公式，地址必须按实际工作簿映射，不能直接套错位置：

- 数量 D5、单价 G5：`=IF(COUNT(D5,G5)=2,D5*G5,"")`。保留真实零值，不把缺失量价算为零。
- 报价 G5、参照 E5：`=IF(COUNT(G5,E5)=2,IF(E5=0,"",G5/E5-1),"")`。
- 总价必须同时判断应计价行是否完整；SUM 忽略空白并不意味着汇总完整。局部已知合计可展示，但命名为“已知金额小计”，缺项时不能充当完整报价总价。
- 同行参与资格以明确的状态/可比字段控制，排除 pending、excluded 和不能比较的记录。需要时用少量辅助单元格输出可参与数值后统计，避免把被排除项变成零影响最小值和中位数。
- 单家不能生成同行排名；参照为零不做倍差；负值按其业务性质处理。禁止用 `IFERROR(...,0)` 把失败掩盖成正常零值。
- 默认保留底层精度，通过显示格式控制小数位；只有项目明确规定逐行舍入时才使用 ROUND，并说明总价是逐行舍入后求和还是最终舍入。

## 图表与文字的联动边界

- 原生 Excel 图表必须引用公式结果区域，用户改输入后数值更新；不得仅写入旧缓存或用静态图片冒充自动更新图表。
- 排名列用公式更新；如果物理行顺序不会自动重排，注明“排名随输入更新，显示顺序可按排名列排序”。不要宣称普通固定表会自动排序。
- Top 10 若标注动态，应建立可更新的排名与取值辅助区，处理并列后再引用；做不到动态时改用完整项目差额图，不继续展示已经过时的 Top 10 名单。
- 价格偏离与阈值提示可以自动更新；专业文字判断、证据适用性、修正是否获确认、Word 报告不会因 Excel 修改而自动重写。在概述页简短说明：“修改测算输入后数值与图表更新，文字意见及 Word 报告需重新核查。”

## 验证及停止条件

先集中设置公式、格式、长文本行高、Word 表头重复和图表位置，再生成。进行一轮完整检查：公式与金额看实际工作簿，排版看渲染图，PDF 提取文本仅作辅助。单独的文本提取缺行或顺序混乱不能据此认定原件内容丢失。

交付前在临时副本中修改一个测算单价和一个工程量，确认测算合价、总价、偏离/金额影响和相关图表按预期变化，且原件校验输入不变；测试后恢复原值。另测缺失值、真实零和并列排名。设置自动计算及打开重算，并实际复算保存；仅设置重算标志不算测试通过。不把测试值留在正式文件。

发现明确问题后只修并复查受影响区域。排版最多修复两轮，仍有问题具体披露；金额或公式错误不受排版次数限制，不能冒称通过。工作表序号不等于 PDF 页码。避免为同一个疑似渲染问题连续检查文本、压缩包、图表归属而无新增证据；用可视结果与工作簿数据交叉确认一次即可。过程汇报聚焦实质问题，不逐页输出内部排查日志。
