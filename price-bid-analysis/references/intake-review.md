# 报价读取与复核

## 文件登记与范围识别

登记文件、投标人、项目、报价轮次、日期和版本。先判断文件之间是同一报价的不同格式，还是不同轮次、不同单位工程或互补附件。无法确认版本对应关系时分别保留，不自动按文件修改时间选最新版。

读取 Excel 的所有相关工作表，包括明细、汇总、措施、其他项目、税费和说明；隐藏表、隐藏行列、合并表头也需判断是否涉及报价。`.xls`、`.xlsx`、`.xlsm` 按环境能力读取，不执行宏。保留数值与公式表达式；公式没有缓存或缓存可能过期时使用可靠计算工具重算，不能把空缓存当零。

PDF 优先读取可用文本层。扫描页或乱码页用获批 OCR/视觉能力；逐页核查相关表格是否完整，处理跨页续表、重复表头、小计和结转，保留页码。识别出的数字是提取值，不天然等于已确认原值。

## 三种复核路径

### 仅 Excel

- 回查异常单元格、公式引用、明细范围、总价、税费和折扣关系。
- 核对材料与施工是否分列、综合价是否已含材料，防止漏计或重复相加。
- 简短说明：`本次未提供 PDF，仅依据 Excel 报价文件进行分析。`

### 仅 PDF

- 对声明总价、重要小计、税费、折扣，以及高金额、异常或低置信度项目的数量、单价、合价回看原页；文本层也需检查列错位。
- 所有可计算明细进行数量×单价与汇总交叉检查。计算不一致时优先区分识别错误与原件算术错误。
- 特别复核小数点、千分位、负号、括号、单位和换页遗漏；无法辨认时保留未知，标为待核实。
- 涉及 OCR/视觉识别时说明：`本次依据 PDF 报价文件分析，涉及文字或图像识别；识别存疑项已标注供核实。` 纯文本提取按实际方式调整措辞，不虚称使用 OCR。

### Excel 与 PDF 同时提供

- 按投标人、轮次、版本及范围配对；不能将第二轮 PDF 与第一轮 Excel 当成同版校验。
- 分别读取两份文件后，核对声明总价、明细覆盖、名称、规格、单位、数量、材料价、施工价、综合价、合价、税费及折扣。不能从 Excel 复制数值后声称是 PDF 独立读取。
- 对可配对的相关明细尽量全量比对。未读、未配对、仅抽查的范围单独登记，不宣称全部一致。
- 差异保留双方原值、定位和影响；不默认 Excel 或 PDF 优先。有明确正式版本依据时记录采用理由，否则标记待核实，暂缓受影响结论。
- 简短说明按实际结果写：`本次已对 Excel 与 PDF 的可对应报价内容交叉核对，差异及未核对范围见算术校验表。` 全量核对无差异时可明确说明。

## 复核状态与交付

`confirmed` 表示已回查原件且口径明确；`pending` 表示仍有疑问；`excluded` 表示替代版本、不在范围或不应参与比较。AI 可以通过原件和勾稽完成确认，不默认所有确认必须由用户完成；只有无法从现有证据解决的重要问题才列入澄清。

确认状态与算术状态分别保存：已确认原件确实填错，不等于算术通过。不可比、缺失或存疑数据可以展示，不进入基准与正式排序。

提示只放报告依据与限制，不另加醒目免责声明。对影响总价、排序和重要判断的差异，在对应结论旁说明。继续完成不受影响的分析，不因一项疑问暂停整个任务。

## 施工内容原文
各家独立提取施工内容、备注、品牌、报价总说明和条件性排除，不从招标清单复制给投标人。包括隐藏列、合并单元格和续页中适用的说明；双源复核增加施工内容与范围字段。按[施工内容与范围对照](construction-content.md)逐项核查，并登记实际覆盖。
