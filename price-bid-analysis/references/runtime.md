# 运行与留存

## 能力边界

本包是智能体 Skill，不是独立评标应用。需运行环境提供 PDF/OCR 或视觉读取、Excel 读取、Word/Excel 生成与校验能力；脚本需要 Python 3.10 及以上，统一计算脚本仅使用标准库。缺少某项工具时用当前可用能力完成对应工作；确实无法读取或生成时如实报告，不把未读内容写成“原件未披露”。

可选经验库与历史报价库通过用户/平台提供的入口读取，见辅助库接口。没有入口也能分析。不要求安装飞书，不因云盘未配置阻塞本地成果交付。

## 项目留存

建议同一项目目录保存：`01_输入原件`、`02_参考证据`、`03_处理底稿`、`04_分析成果`、`05_审计记录`。同项目多轮报价保留轮次，不覆盖原件。

底稿至少保存输入登记、清单映射、读取/双格式复核记录、标准化 JSON、计算结果、库查询状态及采用证据、分析方法、实际阈值和修正记录。修正记录包含原值、新值、理由、确认来源和时间。

可运行 `python scripts/build_audit_manifest.py 项目目录 --project 项目编号 --task-id 任务编号` 生成文件哈希清单。该清单只证明文件快照，不证明分析正确，也不代替人工确认记录。脚本版本/哈希、运行参数另写底稿后一起纳入清单。

## 可选云盘归档

只有用户或已有任务明确要求云盘归档、且存在已授权目标时才进行，使用当前平台提供的文件能力。上传后保存文件标识和可核验结果；失败说明“本地成果已完成，云盘归档未完成”，不影响本地文件交付，不声称已经上云。

不默认创建飞书应用、扩大权限、公开分享、覆盖历史版本或自动将成果写回经验库。原包飞书专用脚本不再作为本 Skill 必经依赖；由平台连接能力负责具体存取。
