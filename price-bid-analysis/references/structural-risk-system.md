# 四维报价结构识别体系

本参考用于方法选择与成果解释。原始报价和已有读取复核优先；经验及统计模型只提供线索。四个维度每次评估适用性，记录已执行/不适用/数据不足及原因，不为执行算法伪造特征。

## 1. 总价偏离分析

区分声明总价、明细复算价、同口径测算价、正式评标价。对账未完成、范围或税费不同的总价保留展示但不进入共同总价统计。可比子集统计列明纳入/排除投标人，不伪装全体排名。

展示同行中位数、均值、极差、总体CV（总体标准差/均值绝对值），总价对控制价与同行分别计算。零/近零均值、负价和少量样本不作强统计推断；两家以直接差额为主，单家无同行统计。总价接近不能证明内部结构正常，继续下钻子目。

## 2. 核心子目结构分析

先确认清单映射、数量、计量单位、规格、工作范围、材料施工关系、税费、轮次。分别建立同行、控制、历史、市场参照；不能合并为不明来源的标准价。

- 相对单价指数 `r_ij = p_ij / median_j`。同一子目至少两条有效报价；正价比值只用于同口径正值。中位数含本家须披露，增加留一法偏离检验参照敏感性。样本中位数不是市场合理成本。
- 金额差额 `D_ij = q_j * (p_ij - median_j)`；统一招标量缺失时不跨家加总。正、负差额分开，另列净额与绝对额，避免互相抵消。金额不跨互斥投标人累加成节省。
- 共同可比子集按 `q_j * median_j` 加权；披露共同项数/全部项数、共同基准金额和未覆盖范围。不能用各家不同覆盖集合比较综合指数，也不能把子集价差称为整项目差异。
- 核心项不只按百分比：同时查看造价占比、绝对价差、工程量敏感性、关键材料与履约影响。阈值沿用项目配置，补充阈值必须有业务依据，不能自动成为否决线。
- 通用与非标/变更敏感类别由AI依据清单与技术范围分类，保留理由和来源；不凭名称自动判定高变更概率。类别内计算加权方向与高低价组合，回到具体项目解释。

## 3. 结构联动关系分析

预先列关联业务假设及证据：材料/施工、混凝土/模板、主项/措施、主体/附属、人工/机械、回收残值/拆除价等。先确认是否包含、另列、甲供或重复计取。不同单位的原始单价不能直接当作物耗比例。

分两类：①相对价格指数比，反映两个项目相对同行的方向差异；②物理消耗或费用比例，需要工程量、几何条件、工艺、分母和外部依据。脚本仅实现第一类，不假装估算物耗。费用占比同时显示绝对金额，防止总价分母变化造成假异常。

一高一低只说明需核查成本归属/范围/工艺，不能推断动机。关联重复指向同一金额时去重，以 finding_id 归集，多个算法重复提示不重复计算影响金额。

## 4. 异常行为检测

读取 [算法与验证](algorithm-protocol.md)。用同口径特征识别局部离群、群体分化和报价相似性；名称匹配与可比性仍由AI核实。聚类、相似性、低密度都不是串标、恶意或低于成本认定。需解释样本单位、特征、被排除记录及异常涉及的清单和金额。

## 情景与结论

工程量情景来源可为图纸、现场、明确业务假设；记录情景依据，不伪造发生概率。固定原单价下 `增量付款=Δq*p`、`相对参照差额=Δq*(p-reference)`。发生重定价、阶梯计价、费率计价时改用项目合同规则，原脚本不适用。情景互斥或关联时不可简单求和。

风险输出统一：`finding_id`、维度、事实、业务解释、替代解释、来源、参照类别、计算/模型版本、涉及金额、覆盖范围、复核状态、澄清问题。优先级按金额及证据判定，不把算法分数硬转成概率。数据问题优先复核；证据不足允许暂不判断。

`python scripts/analyze_structure.py normalized-bids.json --output structure.json`

先调用原分析器沿用准入条件。输出总价统计、子目指数/CV、留一敏感性、共同子集正负价差、已确认关联和情景。其结果为底稿；单元格可计算结果必须落实为Excel公式。扩展输入见 [算法数据约定](algorithm-schema.md)。本工具不负责自动报价提取、类别识别或输出正式Word/Excel。
